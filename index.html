Privacy & Security

Local reading stays local

☁

Cloud features are opt-in

Cloud TTS and translation only send data when you explicitly enable and configure those features.

API keys stored locally

💳

Payments via Stripe

Frequently Asked Questions

Can WebVoice read any web page?

WebVoice works on most pages, but cannot access Chrome internal pages, the Chrome Web Store, browser PDF viewers, protected iframes, heavily sandboxed pages, or pages where text is rendered inside canvas. In those cases, try manually selecting visible text.

Is local reading really private?

Yes. Local reading uses your browser or operating system's built-in text-to-speech engine. Page text never leaves your device unless you enable cloud TTS.

What cloud TTS providers are supported?

WebVoice supports OpenAI, ElevenLabs, Microsoft Azure, Google, Baidu, Tencent, Alibaba, and any custom HTTP endpoint. You configure your own API keys.

How do I upgrade to Pro?

Open the WebVoice popup, go to Settings → Subscription, and follow the Stripe checkout link. Your Pro unlock is tied to your email address.

Can I use my own TTS API keys?

Yes. Pro users can enter their own API keys for OpenAI, ElevenLabs, Azure, Google, Baidu, or any compatible custom endpoint. Keys are stored locally in your browser.
