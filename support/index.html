WebVoice Support

Need help with WebVoice? This page covers common setup and troubleshooting steps.

Contact

When contacting support, please include your browser name, browser version, operating system, and a short description of the issue.

Common Issues

The extension cannot read the current page

Some pages restrict extension access, including:

  • Chrome internal pages (e.g., chrome:// URLs)
  • Chrome Web Store
  • Browser PDF viewers
  • Protected iframes
  • Heavily sandboxed pages
  • Pages where text is rendered inside canvas

Workaround: Try selecting visible text manually and using WebVoice again.

Selected text is not detected

Try selecting the text again, then click the WebVoice selection quick menu or open the popup. Some websites use custom selection layers, shadow DOM, or embedded frames that may limit selection access.

A language has no sound

WebVoice depends on voices available in your browser or operating system for local reading.

  • Windows: Install additional language and speech packs in Windows Settings → Time & Language → Speech
  • macOS: Go to System Settings → Accessibility → Spoken Content → System Voice, then download additional voices
  • Linux: Install speech-dispatcher and additional voice packages via your package manager

Cloud TTS can also provide additional voices if configured in the extension settings.

Translation does not work

Built-in translation support depends on your browser. If your browser does not support built-in translation, configure a cloud translation provider in the extension settings.

Download audio is unavailable

Audio download is available for cloud TTS output only. Local browser voices are for real-time playback and do not provide downloadable audio data.

Subscription verification fails

  • Make sure you entered the same email used at checkout
  • Wait a few minutes — network errors or Stripe rate limits may temporarily prevent verification
  • Check your spam folder for the original purchase confirmation

Voice Installation

WebVoice uses your browser or OS voices for local reading. To get more voices:

  • Chrome: Chrome uses Windows voices on Windows and macOS voices on macOS
  • Install voices directly from your OS settings (see above)
  • For more languages and higher quality, use cloud TTS with your own API key

Cloud TTS Notes

WebVoice Pro supports cloud TTS providers including OpenAI, ElevenLabs, Microsoft Azure, Google, Baidu, Tencent, Alibaba, and custom HTTP endpoints. You provide your own API keys — WebVoice does not access your account or store your keys.

Privacy Summary

Local reading does not upload page text. Cloud TTS or cloud translation sends text only when you enable those features and configure a provider. API keys are stored locally in your browser via Chrome extension storage, not on WebVoice servers.
