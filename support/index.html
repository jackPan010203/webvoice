Troubleshooting and answers for WebVoice

Installing and starting

Install WebVoice from the Chrome Web Store. Open the extension popup, choose a source, and start local reading. No account is required for free local reading.

Cleaning a page

Choose the cleaning preview entry in the popup. The reading view extracts the selected text first, then the main article, then visible content blocks. You can remove blocks, restore them, decide whether headings or author details should be spoken, and copy the cleaned original or translation. Cleaning changes only the temporary reading view, not the source page.

Opening a local book

Use Open local file in the popup and choose an EPUB, TXT, HTML, or Markdown file. The book reader parses the file in the browser, shows its chapters when available, and keeps the current book session temporary. A file larger than 50 MB or a DRM/encrypted EPUB cannot be imported.

Why is a page unavailable?

Chrome internal pages, the Chrome Web Store, browser PDF viewers, protected iframes, canvas-rendered text, and some closed Shadow DOM content are restricted by the browser. Refresh the page after installing or updating the extension, then try a normal web page or select the text manually.

Why is a language missing a voice?

Local reading depends on voices installed in Chrome or your operating system. Install the relevant language or speech pack, restart Chrome, and reopen the voice list. Cloud TTS is optional and depends on the provider and API key configured in Settings.

Cloud TTS, translation, and downloads

Cloud features are optional. When enabled, the text needed for the request is sent to the provider you selected. Provider pricing and limits are separate from WebVoice. Downloadable audio is available only for supported cloud TTS output; local browser voices may not expose an audio file.

Purchase verification

Use the same email entered at Stripe checkout in WebVoice Settings, then choose Verify purchase. The extension checks the purchase through the WebVoice license service and binds the license to the current device, up to the stated five-device limit. A temporary network error keeps the last known local status; try again later if verification cannot complete.

Refunds

Paid monthly charges and lifetime purchases can be eligible for a refund within 7 days. See the Refund Policy for the required details and processing times.
