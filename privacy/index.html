Privacy Policy

How WebVoice handles your data

Effective date: 2026-06-08

Overview

WebVoice is a browser extension that reads selected text or web page content aloud. This privacy policy explains what data WebVoice accesses, how it is used, and your choices.

Data Collection

WebVoice does not collect, sell, or share personal data for advertising purposes.

Local Reading

When using the default local reading mode, selected text and page content are processed locally by your browser or operating system's text-to-speech engine. WebVoice does not upload this text to our servers.

Cloud TTS and Translation

If you enable cloud TTS or cloud translation, the text you choose to read or translate may be sent to the provider you configure. Supported providers include:

  • OpenAI
  • ElevenLabs
  • Microsoft Azure
  • Google
  • Baidu
  • Tencent
  • Alibaba
  • Custom HTTP endpoints

WebVoice does not control those third-party providers. Their own privacy policies apply. We recommend reviewing the privacy policy of any provider you configure.

API Keys

If you enter API keys or tokens for cloud services, they are stored locally in your browser using Chrome extension storage. WebVoice does not sync or transmit your API keys to our servers.

Payments

Payments are handled by Stripe-hosted checkout pages. WebVoice does not collect or store credit card numbers. All payment processing is performed directly by Stripe.

Extension Permissions

WebVoice requests the following permissions:

  • Active tab: Required to read page content after you take action (click or shortcut)
  • Storage: Used to save your settings and API keys locally
  • Download: Used to save cloud TTS audio files when you request a download
  • TTS: Used to access browser text-to-speech for local reading
  • Host permissions: Required only to connect to cloud TTS providers you explicitly configure

What WebVoice Does NOT Do

  • WebVoice does not track your browsing history
  • WebVoice does not collect analytics on your reading habits
  • WebVoice does not sell or share your personal data
  • WebVoice does not access your data when local reading is used

Your Choices

You can control cloud features at any time:

  • Disable cloud TTS in extension settings to stop all outbound requests
  • Clear your extension storage at any time from Chrome settings
  • Uninstall WebVoice at any time to remove all local data
