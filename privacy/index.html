Privacy Policy

Last updated: June 2025

WebVoice does not sell user data.

Local Reading

When using local reading, selected text and page content are processed in the browser or by the operating system voice engine. WebVoice does not upload this text to our servers.

Cloud TTS and Translation

If the user enables cloud TTS or cloud translation, the selected text or extracted page content may be sent to the provider configured by the user, such as OpenAI, ElevenLabs, Microsoft Azure, Google, Baidu, Tencent, Alibaba, DeepL, or a custom HTTP endpoint.

Payments

Payments and subscription verification is handled by Stripe-hosted pages and Stripe APIs. WebVoice does not collect or store credit card numbers.

Stored Locally

WebVoice stores user settings, voice preferences, license status, usage state, device ID, and optional provider configuration in browser extension storage.
